# Top Hat Bakery — concept preview

This is an **unofficial website concept** by Digital Sprout. It is not Top Hat Bakery’s official website and has not been approved by the business. The donut top-hat mark is original concept artwork, not the official bakery logo. The bakery photos were cropped from screenshots you supplied for this local draft.

## Run locally

Open `index.html` directly in a browser, or open this folder in VS Code and use Live Server. There is no build step or package dependency.

- No hours or fixed menu are shown because current public listings conflict and availability can change. The page invites visitors to call ahead.

## Website listing caveat

The lead notes “No Website.” Search results also link to `tophatbakery.co.za`, but the page snapshot available during research describes branches in Phoenix, Verulam, and Tongaat and does not verify the Ferndale location. Confirm whether that domain is connected to this Randburg listing before presenting the lead as having no website.
