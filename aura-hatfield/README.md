# Aura Hatfield — concept preview

An independent, unofficial website concept by Digital Sprout. It is not Aura’s official website and has not been approved by the business.

## Run locally

Open `index.html` in a browser or use VS Code Live Server. There is no build step or package dependency.

## Details used

- Name and area: Aura, Hatfield, Pretoria (as supplied for this concept).
- A public event listing for Aura identifies 1127 Burnett Street, Hatfield, Pretoria. Confirm the current address with the business before relying on it.
- No current official menu, phone number, opening hours, or booking link was verified, so these are not presented as facts.
- The directions link searches Google Maps for Aura at the listed address.

## Logo and photography

- The wordmark and hero bar photo were cropped from the Aura listing screenshots supplied by the user and saved in `assets/`.
- The remaining editorial gallery images are illustrative Unsplash photos, not confirmed photos of Aura. Their photo links and photographer credits appear on the page.
- The screenshots include a low-resolution listing preview; use original image files from Aura if available before any production use.
