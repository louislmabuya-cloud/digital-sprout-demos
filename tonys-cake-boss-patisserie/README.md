# Tony’s Cake Boss Patisserie — concept preview

This is an **unofficial website concept** by Digital Sprout. It is not the patisserie’s official website and has not been approved by the business. The cake and pastry photographs were cropped from screenshots supplied for this local concept. The badge and visual layout are original concept work.

## Run locally

Open `index.html` in a browser, or open this folder in VS Code and use Live Server. There is no build step or package dependency.
